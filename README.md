# FAB

**Floating action buttons for Vue — fixed and draggable.**

Two components: a standard floating action button, and one the user can drag anywhere in the viewport.

```vue
<FabComponent />
<DraggableFabComponent />
```

## Why the draggable one exists

A floating button always covers something. On dense screens — tables, editors, dashboards — the thing it covers is usually the thing the user needs. Letting them move it out of the way costs nothing and removes an entire category of complaint.

## Install

```bash
npm install innoboxrr-fab
```

Register the components globally, or import them where needed.
